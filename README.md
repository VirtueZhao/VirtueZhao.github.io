# VirtueZhao.github.io

Personal academic homepage of Di Zhao — live at **https://virtuezhao.github.io**.

Built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io)
Jekyll template and hosted on GitHub Pages.

## Editing content

The site is currently filled with **placeholder content**. Files to edit:

| What | Where |
|------|-------|
| Homepage (bio, research interests, news) | `_pages/about.md` |
| Sidebar info, social links, site config | `_config.yml` |
| Top navigation menu | `_data/navigation.yml` |
| Publications | `_publications/*.md` |
| Talks | `_talks/*.md` |
| Teaching | `_teaching/*.md` |
| CV | `_pages/cv.md` |
| Profile photo | `images/bio-photo.jpg` |

After editing, commit and push to `main`; GitHub Pages rebuilds automatically
within a minute or two.
